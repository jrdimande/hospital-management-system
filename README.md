# Sistema de Atendimento Hospitalar

## Descrição

Este projecto consiste no desenvolvimento de um **Sistema de Atendimento
Hospitalar** em **Java**, utilizando **Programação Orientada a Objectos
(POO)**, **Estruturas de Dados** e a arquitetura **MVC
(Model-View-Controller)**.

O sistema simula o atendimento de pacientes em uma clínica ou hospital,
organizando o fluxo desde a chegada até ao atendimento médico.

------------------------------------------------------------------------

## Objectivo

Desenvolver um sistema simples que permita **organizar o atendimento de
pacientes**, utilizando estruturas de dados implementadas manualmente.

------------------------------------------------------------------------

## Funcionalidades

-   Cadastrar paciente
-   Atualizar dados do paciente
-   Listar pacientes
-   Adicionar paciente na fila
-   Definir prioridade (Alta, Média, Baixa)
-   Chamar próximo paciente
-   Atender paciente
-   Registrar histórico de atendimento
-   Visualizar histórico

------------------------------------------------------------------------

## Usuários do Sistema

### Recepcionista

-   Registra pacientes
-   Adiciona pacientes na fila


### Médico

-   Chama pacientes
-   Realiza atendimento
-   Registra observações

### Administrador

-   Gerencia dados
-   Consulta histórico
-   Controla usuários do sistema

------------------------------------------------------------------------

## Estruturas de Dados Utilizadas

-   Lista Duplamente Ligada
-   Fila
-   Fila com Prioridade
-   Pilha

------------------------------------------------------------------------

## Arquitetura do Sistema

### MVC --- Model, View e Controller

**Model** - Dados do sistema - Estruturas de dados - Regras de negócio

**View** - Interface do usuário - Menus do sistema

**Controller** - Controlar operações - Comunicação entre Model e View

------------------------------------------------------------------------


## Fluxo Básico do Sistema

1.  Paciente chega ao hospital
2.  Recepcionista registra o paciente
3.  Paciente é adicionado à fila
4.  Enfermeiro define prioridade
5.  Médico chama o próximo paciente
6.  Médico realiza atendimento
7.  Sistema registra o atendimento no histórico
